# Metadatos de tiendas — RC5
**Nombre:** Finanzia
**Subtítulo:** Tu vida financiera, en equilibrio
**Descripción corta:** Organiza cuentas, gastos, presupuestos, metas y deudas desde un solo lugar.

Finanzia es una aplicación de organización financiera personal para visualizar cuentas, registrar ingresos y gastos, planificar presupuestos, seguir metas de ahorro, controlar deudas y revisar reportes. Incluye modo claro/oscuro, privacidad para ocultar importes, exportación CSV/PDF, alertas y sincronización opcional.

Pendiente antes de publicar: URL pública de privacidad, URL/correo de soporte, screenshots reales, iconos/splash nativos definitivos y cuestionarios de privacidad según el comportamiento final.
