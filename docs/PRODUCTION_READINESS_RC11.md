# Finanzia RC11 · Producción

## Gates obligatorios
- [ ] GitHub Actions: formato, analyze, tests, Web, Android AAB e iOS sin firma en verde.
- [ ] Dos usuarios reales de staging validan RLS en todas las tablas.
- [ ] Dos dispositivos validan edición simultánea, creación, borrado, offline/reconexión y conflicto.
- [ ] Eliminación de cuenta E2E aprobada, incluyendo reintento tras fallo parcial.
- [ ] PIN/biometría probado en Android e iOS físicos.
- [ ] CSV/PDF compartir/guardar validado en Android/iOS y descarga en Web.
- [ ] Notificaciones: permisos, duplicados, reaparición de alertas y vencimientos.
- [ ] Registro, login, logout, recuperación de contraseña y cambio de correo.
- [ ] Accesibilidad: TalkBack, VoiceOver, teclado Web, escalado de texto.
- [ ] Política de Privacidad y Términos definitivos publicados.
- [ ] Iconos, splash, package IDs, firma y metadatos de tiendas definitivos.

No promover a 1.0 si cualquiera de estos gates sigue sin evidencia real.
