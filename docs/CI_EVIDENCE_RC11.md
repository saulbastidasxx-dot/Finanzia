# Evidencia de CI

Para cada candidato guardar:
- URL o ID del workflow run.
- Commit SHA exacto.
- Resultado de `dart format`, `flutter analyze`, `flutter test`.
- Resultado de builds Web, Android AAB e iOS sin firma.
- Logs de cualquier fallo y commit que lo corrige.

Una RC solo puede considerarse validada si la evidencia corresponde al mismo commit distribuido.
